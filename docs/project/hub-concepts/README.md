# Hub portal concepts (paused, 2026-10-27)

The owner asked for the hub (`jerryqiu.com`) to become a portal/dimension experience: entering the site, then travelling to the other worlds (photo, music, flying, make), with a light Ready Player One feel. Order agreed: settle the theme first, then write structure docs (hub and photography only), then build.

No theme is approved yet. Nothing here is in the apps; these are standalone preview pages (open in a browser).

| --- | --- | --- |

Worlds: Exposure (red, photo), Resonance (amber, music), Altitude (cyan, flying), Forge (green, make). | "All cool but not the vibe." Later: **Nexus was closest to the vision, but still a long way from good.** |
| `02-sky-islands-3d.html` | Three.js (r128 from cdnjs) floating-island hub inspired by The Hunt: Roblox 20, with portals, gold keys and a sealed Island ∞. | Rejected: no 3D render. |
| `03-2d-moods.html` | Six flat 2D moods: title screen, world select, portal dive, pixel overworld, sticker poster, holo scanner. | Rejected: "all terrible". |

Takeaways for the next attempt: start from Nexus, no 3D renders, and aim for something genuinely extraordinary rather than a game-UI or poster pastiche. The owner referenced the Roblox 20th birthday Hunt visuals as the bar for "cool".
